data channel open — p2p file sharing

Send files phone-to-phone, no cloud in the middle

A minimal demo on top of react-native-webrtc data channels: pick a file, chunk it into 64KB pieces, stream it over the peer connection, and reassemble it on the other phone. Signaling from the Expo example is reused — concepts from the field guide.

01

What you build

Two phones join the same room. The sender picks a document, the app sends a small JSON header (name, size, chunks), then streams the chunks. The receiver shows a progress bar and saves the file locally. File bytes never touch your server.

Signal Same offer / answer / ICE handshake as video calls — over your Socket.IO server.
Header Sender transmits { kind: 'meta', name, size, chunks } as a string.
Chunks Sender transmits { kind: 'chunk', i, data } pieces (~64KB), waiting when bufferedAmount grows.
Done Receiver joins the pieces in order, writes one file, shows it in a received list.

03

Reuse the same signaling

No new server code. Join the same room from lib/socket.ts, run the same offer/answer/ICE exchange as the call hook — but skip getUserMedia entirely. Data channels need no camera or microphone permission.

lib/chunk.tsexport const CHUNK_SIZE = 64 * 1024;

export function sliceBase64(b64: string): string[] {
  const out: string[] = [];
  for (let i = 0; i < b64.length; i += CHUNK_SIZE) {
    out.push(b64.slice(i, i + CHUNK_SIZE));
  }
  return out;
}
04

Sender: create the channel, stream chunks

The caller creates the channel before creating the offer — per the official BasicUsage doc. Respect bufferedAmount so a big file doesn't flood the channel.

hooks/useFileShare.ts — sender partconst channel = pc.createDataChannel('file-share', { ordered: true });
channel.binaryType = 'arraybuffer';

async function sendFile(name: string, size: number, pieces: string[]) {
  await new Promise<void>((res) => {
    if (channel.readyState === 'open') res();
    else channel.onopen = () => res();
  });

  channel.send(JSON.stringify({ kind: 'meta', name, size, chunks: pieces.length }));

  for (let i = 0; i < pieces.length; i++) {
    while (channel.bufferedAmount > 256 * 1024) {
      await new Promise((r) => setTimeout(r, 50));
    }
    channel.send(JSON.stringify({ kind: 'chunk', i, data: pieces[i] }));
    onProgress?.(i + 1, pieces.length);
  }
  channel.send(JSON.stringify({ kind: 'done' }));
}
05

Receiver: collect, reassemble, save

The callee never calls createDataChannel — the channel arrives via ondatachannel. Buffer pieces by index, join on done, write once with expo-file-system.

hooks/useFileShare.ts — receiver partpc.ondatachannel = (event) => {
  const rx = event.channel;
  let meta: { name: string; chunks: number } | null = null;
  const parts: string[] = [];

  rx.onmessage = async (e) => {
    const msg = JSON.parse(typeof e.data === 'string' ? e.data : new TextDecoder().decode(e.data));

    if (msg.kind === 'meta') {
      meta = msg;
    } else if (msg.kind === 'chunk') {
      parts[msg.i] = msg.data;
      onReceiveProgress?.(parts.filter(Boolean).length, meta?.chunks ?? 0);
    } else if (msg.kind === 'done' && meta) {
      const uri = FileSystem.documentDirectory + meta.name;
      await FileSystem.writeAsStringAsync(uri, parts.join(''), {
        encoding: FileSystem.EncodingType.Base64,
      });
      onFileSaved?.(uri, meta.name);
    }
  };
};

Sending base64-as-JSON keeps the demo simple and debuggable. For raw bytes, send ArrayBuffer chunks with binaryType = 'arraybuffer' instead — same handshake, same channel.

06

UI: pick, send, watch progress

app/share.tsximport { useState } from 'react';
import { Button, Text, View } from 'react-native';
import *DocumentPicker from 'expo-document-picker';
import *FileSystem from 'expo-file-system';
import { sliceBase64 } from '../lib/chunk';

export default function ShareScreen() {
  const [pct, setPct] = useState(0);
  const [saved, setSaved] = useState<string[]>([]);

  async function pickAndSend() {
    const picked = await DocumentPicker.getDocumentAsync({});
    if (picked.canceled) return;
    const file = picked.assets[0];
    const b64 = await FileSystem.readAsStringAsync(file.uri, {
      encoding: FileSystem.EncodingType.Base64,
    });
    const pieces = sliceBase64(b64);
    await sendFile(file.name, file.size ?? b64.length, pieces);
  }

  return (
    <View style={{ flex: 1, padding: 24, justifyContent: 'center' }}>
      <Button title="Pick + send file" onPress={pickAndSend} />
      <Text>Sending: {pct}%</Text>
      {saved.map((uri) => <Text key={uri}>Saved: {uri}</Text>)}
    </View>
  );
}

Wire onProgress to setPct and onFileSaved to append to saved. Hang-up: close the data channel, then pc.close() like a call.

07

Limits and debugging

Symptom Fix
Channel never opens Create it before createOffer (caller) and listen via ondatachannel (callee).
Large files stall Keep 64KB chunks, honor bufferedAmount backpressure as above.
Works on Wi-Fi, fails on cellular Add TURN to lib/webrtc.ts — symmetric NATs need a relay.
Received file is corrupt Index pieces by i and join in order; don't append arrival order blindly.
