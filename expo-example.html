dev-client build — expo-router + webrtc

Expo video calls, from blank project to two phones

An end-to-end build with expo-router + react-native-webrtc: scaffold the app, install the native module, ship a development build, run a tiny signaling server, handle permissions, and render the call UI. For the WebRTC concepts underneath, read the field guide first.

01

What you build

Two phones join the same room name (e.g. demo) and get a 1:1 video call. A small Node + Socket.IO server only passes join / offer / answer / ice-candidate messages — media flows peer-to-peer after that.

folder layout — webrtc-expo/app/
  _layout.tsx          # expo-router Stack
  index.tsx            # join screen (room name input)
  call/[room].tsx      # call screen (RTCView + controls)
hooks/useCall.ts       # peer connection + signaling wiring
lib/socket.ts          # socket.io client singleton
lib/permissions.ts     # camera + mic permission helper
lib/webrtc.ts          # ICE servers + config
server/
  package.json
  server.js            # tiny signaling server
app.json               # expo config: router, permissions, scheme
You need two physical devices. Simulators lack cameras and react-native-webrtc needs native code — so this whole guide targets a expo-dev-client development build, never Expo Go.

Match versions per the official config-plugin table — e.g. Expo 52 → react-native-webrtc@124.0.4 + @config-plugins/react-native-webrtc@10.0.0. The plugin sets minSdk 24 and android.enableDexingArtifactTransform.desugaring=false for you (required by the official Android guide).

Package Why

terminalnpx expo start --dev-client

Expo Go will fail here with missing native module errors. If you see Cannot find native module 'WebRTCModule', you're in Go — switch to the dev-client build.
06

Create the signaling server

One file, no auth, LAN-friendly. It just relays messages inside a room. Run it on your laptop; phones reach it via your machine's LAN IP (e.g. http://192.168.1.20:3000).

server/server.jsconst { Server } = require('socket.io');
const io = new Server(3000, { cors: { origin: '*' } });

io.on('connection', (socket) => {
  socket.on('join', (room) => {
    socket.join(room);
    socket.to(room).emit('peer-joined');
  });

  socket.on('offer', ({ room, offer }) =>
    socket.to(room).emit('offer', offer));
  socket.on('answer', ({ room, answer }) =>
    socket.to(room).emit('answer', answer));
  socket.on('ice-candidate', ({ room, candidate }) =>
    socket.to(room).emit('ice-candidate', candidate));
});

console.log('signaling on :3000');
lib/socket.ts — client singletonimport { io, Socket } from 'socket.io-client';

// use your laptop LAN IP, not localhost — phones are separate devices
export const SIGNALING_URL = 'http://192.168.1.20:3000';

let socket: Socket | null = null;
export function getSocket() {
  if (!socket) socket = io(SIGNALING_URL, { transports: ['websocket'] });
  return socket;
}

07

Handle camera + mic permissions

Ask before getUserMedia. Android will reject the capture otherwise, and iOS needs the usage strings from app.json.

lib/permissions.tsimport { Camera } from 'expo-camera';

export async function ensurePermissions(): Promise<boolean> {
  const cam = await Camera.requestCameraPermissionsAsync();
  const mic = await Camera.requestMicrophonePermissionsAsync();
  return cam.status === 'granted' && mic.status === 'granted';
}
08

Wire the call logic

One hook owns the peer connection: grabs the camera, joins the socket room, does offer/answer/ICE, and exposes the two streams plus hang-up. The second phone to join becomes the caller.

hooks/useCall.tsimport { useEffect, useRef, useState } from 'react';
import {
  RTCPeerConnection, RTCIceCandidate, RTCSessionDescription,
  mediaDevices, MediaStream,
} from 'react-native-webrtc';
import { getSocket } from '../lib/socket';
import { RTC_CONFIG } from '../lib/webrtc';
import { ensurePermissions } from '../lib/permissions';

export function useCall(room: string) {
  const [local, setLocal] = useState<MediaStream | null>(null);
  const [remote, setRemote] = useState<MediaStream | null>(null);
  const [status, setStatus] = useState('joining');
  const pc = useRef<RTCPeerConnection | null>(null);

  useEffect(() => {
    let alive = true;
    const socket = getSocket();

    async function setup() {
      const ok = await ensurePermissions();
      if (!ok || !alive) { setStatus('blocked'); return; }

      const stream = await mediaDevices.getUserMedia({
        audio: true, video: { frameRate: 30, facingMode: 'user' },
      });
      if (!alive) return;
      setLocal(stream);

      const peer = new RTCPeerConnection(RTC_CONFIG);
      pc.current = peer;
      stream.getTracks().forEach((t) => peer.addTrack(t, stream));

      peer.ontrack = (e) => alive && setRemote(e.streams[0]);
      peer.onicecandidate = (e) => {
        if (e.candidate) socket.emit('ice-candidate', { room, candidate: e.candidate });
      };
      peer.onconnectionstatechange = () => alive && setStatus(peer.connectionState);

      socket.emit('join', room);

      // second to join calls first — 'peer-joined' means someone is waiting
      socket.on('peer-joined', async () => {
        const offer = await peer.createOffer();
        await peer.setLocalDescription(offer);
        socket.emit('offer', { room, offer });
      });
      socket.on('offer', async (offer) => {
        await peer.setRemoteDescription(new RTCSessionDescription(offer));
        const answer = await peer.createAnswer();
        await peer.setLocalDescription(answer);
        socket.emit('answer', { room, answer });
      });
      socket.on('answer', async (answer) => {
        await peer.setRemoteDescription(new RTCSessionDescription(answer));
      });
      socket.on('ice-candidate', async (c) => {
        await peer.addIceCandidate(new RTCIceCandidate(c));
      });
    }
    setup();

    return () => {
      alive = false;
      socket.off('peer-joined');
      socket.off('offer');
      socket.off('answer');
      socket.off('ice-candidate');
      pc.current?.close();
    };
  }, [room]);

  function hangUp(localStream: MediaStream | null) {
    localStream?.getTracks().forEach((t) => t.stop());
    pc.current?.close();
  }

  return { local, remote, status, hangUp };
}
09

Build the UI screens

Join screen collects a room name; call screen shows remote full-screen, local picture-in-picture, and mute / flip / hang-up controls.

app/index.tsx — joinimport { useState } from 'react';
import { Button, TextInput, View, Text } from 'react-native';
import { useRouter } from 'expo-router';

export default function Join() {
  const [room, setRoom] = useState('demo');
  const router = useRouter();
  return (
    <View style={{ flex: 1, justifyContent: 'center', padding: 24 }}>
      <Text>Room</Text>
      <TextInput value={room} onChangeText={setRoom} autoCapitalize="none" />
      <Button title="Join call" onPress={() => router.push(`/call/${room}`)} />
    </View>
  );
}
app/call/[room].tsx — callimport { useState } from 'react';
import { View, Button, Text } from 'react-native';
import { useLocalSearchParams, useRouter } from 'expo-router';
import { RTCView } from 'react-native-webrtc';
import { useCall } from '../../hooks/useCall';

export default function CallScreen() {
  const { room } = useLocalSearchParams<{ room: string }>();
  const router = useRouter();
  const { local, remote, status, hangUp } = useCall(room);
  const [isFront, setIsFront] = useState(true);

  async function flip() {
    const track = local?.getVideoTracks()[0];
    await track?.applyConstraints({ facingMode: isFront ? 'environment' : 'user' });
    setIsFront(!isFront);
  }

  return (
    <View style={{ flex: 1, backgroundColor: '#000' }}>
      {remote
        ? <RTCView streamURL={remote.toURL()} style={{ flex: 1 }} objectFit="cover" />
        : <Text style={{ color: '#fff', padding: 24 }}>{status} — waiting for peer…</Text>}
      {local && (
        <RTCView
          streamURL={local.toURL()}
          style={{ position: 'absolute', top: 48, right: 16, width: 110, height: 150 }}
          objectFit="cover" mirror
        />
      )}
      <View style={{ flexDirection: 'row', justifyContent: 'space-around', padding: 20 }}>
        <Button title="Flip" onPress={flip} />
        <Button title="Mute" onPress={() => local?.getAudioTracks().forEach((t) => (t.enabled = !t.enabled))} />
        <Button title="Hang up" color="red"
          onPress={() => { hangUp(local); router.back(); }} />
      </View>
    </View>
  );
}

Mute toggles track.enabled (stays connected). Flip uses track.applyConstraints({ facingMode }) — _switchCamera() is deprecated since v124.0.5 per the official BasicUsage. Hang-up stops tracks and closes the peer connection.

10

Run it and debug

  1. Start signaling: node server/server.js — note your LAN IP.
  2. Set SIGNALING_URL in lib/socket.ts to http://<LAN-IP>:3000.
  3. Start JS: npx expo start --dev-client, open the dev build on both phones.
  4. Join the same room on both — second to join dials, first answers automatically.
Symptom Fix
WebRTCModule missing You're in Expo Go — open the dev-client build instead.
Stuck on "joining" Phones can't reach the server — same Wi-Fi, LAN IP (not localhost), firewall open on :3000.
Black remote video Permissions denied or ontrack missed — re-grant, reload both clients.
Works on Wi-Fi, fails on cellular Add a TURN server to lib/webrtc.ts.
